# Pedoman Gaya Bahasa & Tata Naskah Dinas Universitas Kadiri (UNIK)

## 1. Diksi dan Sapaan Resmi
- Gunakan sapaan resmi: *"Yth. Bapak/Ibu [Nama Jabatan / Instansi]"* atau *"Yth. Civitas Academica Universitas Kadiri"*.
- Kata ganti instansi pengirim menggunakan *"kami"* (bukan *"saya"*).
- Kata ganti penerima dalam isi surat menggunakan *"Bapak/Ibu"* atau *"Saudara"* (dengan huruf kapital).

## 2. Struktur Alinea Naskah
1. **Alinea Pembuka**:
   - Untuk rapat/kegiatan: *"Sehubungan dengan rencana pelaksanaan agenda [Nama Agenda] di lingkungan Universitas Kadiri, bersama ini kami mengundang Bapak/Ibu untuk hadir pada:"*
   - Untuk permohonan/izin: *"Dalam rangka mendukung kelancaran kegiatan [Nama Kegiatan], bersama surat ini kami bermaksud mengajukan permohonan..."*
   - Untuk edaran/pemberitahuan: *"Menindaklanjuti arahan Pimpinan Universitas Kadiri terkait [Topik], dengan ini kami sampaikan beberapa hal penting sebagai berikut:"*
   - Untuk surat tugas: *"Dalam rangka menjalankan tugas Tri Dharma Perguruan Tinggi dan pengembangan kelembagaan, Pimpinan Universitas Kadiri memberikan tugas kepada:"*

2. **Alinea Isi / Rincian Data**:
   - Selalu format data jadwal menggunakan daftar tidak bernomor (`<ul><li>...</li></ul>`):
     - `<strong>Hari, Tanggal:</strong> [Hari], [Tanggal Bulan Tahun]`
     - `<strong>Waktu:</strong> [Pukul] WIB s.d. Selesai`
     - `<strong>Tempat:</strong> [Ruang / Gedung / Daring]`
     - `<strong>Agenda:</strong> [Agenda Rapat / Pembahasan]`

3. **Alinea Penutup**:
   - *"Mengingat pentingnya agenda tersebut, kami mengharapkan kehadiran Bapak/Ibu tepat pada waktunya."*
   - *"Demikian surat [undangan/permohonan/pemberitahuan] ini kami sampaikan. Atas perhatian dan kerja sama yang baik, kami ucapkan terima kasih."*
